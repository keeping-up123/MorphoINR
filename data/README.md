# Human_Brain_prefrontal_cortex_151507 data location

The repository includes the `Human_Brain_prefrontal_cortex_151507` example under:

```text
data/random/Human_Brain_prefrontal_cortex_151507/
```

The directory contains the base AnnData file, the Phikon-enriched input, the first-stage aligned output, and the matching histology image. The complete preparation and training workflow is documented in [the root README](../README.md) and [the reproducibility checklist](../docs/reproducibility.md).

The Human prefrontal cortex source is distributed by the dataset provider through [Globus](https://app.globus.org/file-manager?origin_id=abdefb8c-731b-4907-a89d-9b5649d9967a&origin_path=%2F&two_pane=false). The files in this repository are the prepared example artifacts required by the included configurations; verify the provider's access and redistribution terms before creating another public copy.

Training-generated logs, checkpoints, and reconstructions are ignored by default.
