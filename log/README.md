# Experiment outputs

The `Human_Brain_prefrontal_cortex_151507` configurations write generated files under:

- `log/random/Human_Brain_prefrontal_cortex_151507/aealign/`: aligned-AE checkpoints, TensorBoard logs, and the logger copy of the stage-1 prediction;
- `log/random/Human_Brain_prefrontal_cortex_151507/inr_aealign_film_zlocal_siren/`: FiLM-SIREN checkpoints, decoder weights, and `reconstructed-val.h5ad`.

Large outputs are ignored by default. Use Git LFS or a GitHub Release if archived checkpoints or predictions are distributed.
