# Scripts

- `train_aligned_film.sh`: runs the aligned AE stage, prepares the generated stage-1 AnnData file, and runs the FiLM-SIREN stage for one case.
- `preprocess/`: creates or merges histology feature matrices.
- `diagnostics/`: checks checkpoints and reconstructed AnnData files.


Run scripts from the project root or use the path-resolving entry points that are documented in each script.
