# Scripts

- `train_aligned_film.sh`: runs the `Human_Brain_prefrontal_cortex_151507` aligned AE and FiLM-SIREN stages.
- `preprocess/`: creates or merges histology feature matrices.
- `diagnostics/`: checks checkpoints and reconstructed AnnData files.


Run scripts from the project root or use the path-resolving entry points that are documented in each script. The release is intentionally instantiated for `Human_Brain_prefrontal_cortex_151507`; edit the YAML files and script together when adding another case.
